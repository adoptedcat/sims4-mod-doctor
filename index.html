Verify your copy

  1. Download only from Alpra's official release page.
  2. Keep the executable, licence, security guide and checksum file together.
  3. Click MADE BY ALPRA inside the program to view its SHA-256 value.
  4. Compare that value with the official release's SHA256SUMS.txt.
  5. Once code signing is enabled, confirm the Alpra signature under Windows File Properties → Digital Signatures.

Important safety rule

Never save an important Sims 4 game while mods or custom content are disabled. Exit without saving, then restore the files through Mod Doctor.
